## 0. 上架前必须先决定的 3 件事

| # | 问题 | 现状 | 结论 |
|---|---|---|---|
| 1 | **名称里有第三方品牌** | 原叫「Agnes 闪电翻译」。Agnes AI 是别人的公司（`agnes-ai.com`），只是本插件支持的一家服务商 | ✅ 已改名 **顺手翻译**，manifest / 设置页 / 弹窗 / 打包全部同步 |
| 2 | **隐私政策网址** | 还没有 | 必须有。`docs/privacy-policy.html` 已写好，托管后把网址填进后台 |
| 3 | **谷歌免费通道的合规性** | 用的是 `translate.googleapis.com` + `client=dict-chrome-ex`，这是 Chrome 浏览器自己调用的参数，不是公开 API | 商店审核大概率能过，但属于**灰色地带**，Google 随时可能封。建议把它定位成「加速层」而非「核心功能」，且不要在任何宣传里写「谷歌翻译官方接口」 |

> **为什么没叫「三空格翻译」**：查了一下，「在输入框连敲三次空格」这个交互是
> **沉浸式翻译**（Chrome 商店下载量最大的翻译扩展之一）的招牌功能，多个教程都在讲。
> 名字里挂「三空格」等于把自己定位成它的仿制品，既不体面也容易被投诉。
> 交互可以一样（交互不受保护），但**品牌必须另起一个**。

## 0.5 操作顺序（照着做）

### 第 1 步：注册开发者账号（约 15 分钟 + 一次性 $5）

1. 打开 <https://chrome.google.com/webstore/devconsole>
2. 用你的 Google 账号登录 → 同意开发者协议 → 付 **$5 一次性注册费**（信用卡，终身有效，不是年费）
3. 填开发者名称（会公开显示在商店页上）、联系邮箱
4. **开启两步验证**（Google 账号安全设置里）。不开 2FA 后面无法提交
5. 新账号可能需要**身份验证**（上传证件）。这一步最慢，可能要 1–3 天，建议今天就做

### 第 2 步：托管隐私政策

`docs/privacy-policy.html` 需要有一个**公网可访问的网址**。三种做法，任选：

- **最快**：GitHub 建仓库 → 上传这个文件 → Settings → Pages → 开启，得到 `https://<用户名>.github.io/<仓库>/privacy-policy.html`
- 或者拖到 Netlify Drop（<https://app.netlify.com/drop>），不用注册就能拿到临时网址
- 或者用你自己的域名

上传前把文件里两个占位符替换掉：

| 占位符 | 换成 |
|---|---|
| `__EXTENSION_ID__` | 商店分配后才有，第一次可以先写「Chrome 应用商店」 |
| `__CONTACT_EMAIL__` | 你能长期收信的邮箱（审核员会点这个链接验证） |

### 第 3 步：创建条目并上传

1. 开发者控制台 → **新增项目**
2. 上传 `dist/agnes-translator-1.9.2.zip`
3. 按第 1 节填商品详情、第 2 节传图
4. 按第 3 节填隐私权（**这部分最容易被打回，逐字照抄上面的理由**）
5. 按第 4 节设分发范围
6. 点 **提交审核**

### 第 4 步：等

- 首次审核 1–3 个工作日；带 `<all_urls>` + `tabs` 的权限组合通常 3–7 天
- 被拒会收到邮件说明违反哪一条，改完重新提交即可，**不额外收费**

## 3. 隐私权（Privacy practices）

### 3.1 单一用途说明（Single purpose）

```
把用户在网页输入框中输入的文字翻译成目标语言，并替换回原输入框。
```

### 3.2 权限理由（逐条填）

**`storage`**
```
保存用户的设置（目标语言、语气风格、网站黑名单）、用户自己填写的 API Key、翻译缓存和接口延迟统计。全部存放在本机 chrome.storage.local，不上传。
```

**`scripting`**
```
扩展安装完成后，把内容脚本补注入到「已经打开」的标签页。因为声明式 content_scripts 只对安装之后新加载的页面生效，不补注入的话，用户装完插件后不刷新页面会以为插件没反应。
```

**`tabs`**
```
查询当前打开的标签页，用于两件事：① 安装后向已打开的页面补注入脚本；② 弹窗里向当前标签页发送消息，读取/写入输入框内容。
```

**`activeTab`**
```
用户点击工具栏图标打开弹窗时，仅对当前标签页生效，用于触发翻译或切换开关。
```

**主机权限 `https://translate.googleapis.com/*`**
```
默认启用的免费翻译通道。用户触发翻译时，把待翻译文字 POST 到该地址取回译文。这是零配置可用的基础。
```

**主机权限 `https://api.groq.com/*`**
```
可选的 AI 翻译服务商。仅在用户自己填写 Groq API Key 并启用该服务商时才会请求。
```

**主机权限 `https://open.bigmodel.cn/*`**
```
可选的 AI 翻译服务商（智谱 GLM）。仅在用户自己填写 API Key 并启用该服务商时才会请求。
```

**主机权限 `https://apihub.agnes-ai.com/*`**
```
可选的 AI 翻译服务商。仅在用户自己填写 API Key 并启用该服务商时才会请求。
```

**主机权限 `<all_urls>`**
```
核心功能要求：用户可能在任何网站的输入框里打字（邮箱、论坛、电商、后台系统），内容脚本必须能在这些页面上运行才能捕获「连敲三次空格」这个手势。扩展不读取页面正文，只在用户主动触发时读取当前聚焦输入框中的文字。
```

### 3.3 远程代码

选 **「否，我没有使用远程代码」**。
所有 JS 都打包在安装包里，没有 `eval`、没有动态加载脚本、没有 CDN 引用。

### 3.4 数据使用情况（逐项勾选）

| 项目 | 勾选 | 理由 |
|---|---|---|
| 个人身份信息 | ❌ 不勾 | 不收集姓名、邮箱、账号 |
| 健康信息 | ❌ 不勾 | — |
| 财务与付款信息 | ❌ 不勾 | 不涉及支付 |
| **身份验证信息** | ✅ **勾** | 用户可自行填写第三方 API Key，属于认证凭据 |
| 个人通讯 | ❌ 不勾 | 不读取邮件 / 聊天内容 |
| **位置信息** | ❌ 不勾 | 不获取地理位置 |
| **网站内容** | ✅ **勾** | 用户主动触发时，读取输入框中的文字并发送给翻译服务 |
| 网页浏览记录 | ❌ 不勾 | 不记录访问过哪些网站 |
| 用户活动 | ❌ 不勾 | 不做行为分析 |

**三个承诺全部勾选**（必须勾，否则不能提交）：
- ✅ 不会将用户数据出售给第三方
- ✅ 不会将用户数据用于与单一用途无关的目的
- ✅ 不会将用户数据用于判定信用度或用于放贷

## 5. 提交后

- 首次审核一般 **1–3 个工作日**；带 `<all_urls>` 和 `tabs` 这类敏感权限的会久一些，可能 5–7 天。
- 被拒最常见的原因：权限理由写得笼统（「为了提升用户体验」这类）、隐私政策和实际行为不符、截图里出现别的品牌 logo。
- 审核通过后，**已安装的用户不会自动更新**（当前是开发者模式加载的），需要他们从商店重新安装。
- 后续每次更新：改 `manifest.json` 的 `version` → 重新 `python tools/build_store.py` → 后台上传新 zip。版本号必须比线上大。
